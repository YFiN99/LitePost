# 🚀 Overview

LitePost is a decentralized social networking platform built on **LitVM**.

Instead of relying on centralized servers, every interaction is executed directly on-chain through smart contracts.

LitePost demonstrates how Web3 can power censorship-resistant social applications while maintaining a clean, modern user experience.

---

# ✨ Features

- 👤 Wallet Authentication
- 📝 Create On-chain Posts
- ❤️ Like Posts
- 💬 Comment on Posts
- 🔁 Repost Content
- 👥 Decentralized User Profiles
- ⚡ Fast React + Vite Frontend
- 🔗 Ethers.js Integration
- 🌌 Aurora Blue UI
- 📱 Responsive Design
- 🔒 Fully On-chain Social Experience

# ⚙ Installation

Clone the repository

```bash
git clone https://github.com/YFiN99/LitePost.git
```

Enter the project

```bash
cd LitePost
```

Install dependencies

```bash
npm install
```

Start development server

```bash
npm run dev
```

Production build

```bash
npm run build
```

Preview production build

```bash
npm run preview
```

# 📦 Smart Contract

LitePost uses a Solidity smart contract deployed on LitVM.

Main functionalities include:

- createProfile()
- updateProfile()
- createPost()
- toggleLike()
- commentPost()
- repost()
